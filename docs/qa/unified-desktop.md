# Единый десктоп RocketMon · 24 ноября 2026

В отличие от ноябрьской Studio-сборки, приложение использует только `MainWindow`. Старые страницы, «Студия сигналов» и «Ручная торговля» находятся в одном меню. Экраны — Avalonia, не браузер. Старый установочный скрипт перенаправляет в сборку `RocketMon.app`, а не в прежнее отдельное окно.

## Проверка и воспроизведение

- Из checkout: `RCKTMON_UI_ARTIFACTS=/путь/для/кадров dotnet test RcktMon.slnx -c Release -p:TreatWarningsAsErrors=true`. Для тестов используются локальные имитаторы источников, брокера и хранилища ключей. Доступ к действующему счёту не нужен.
- Нативные Skia-кадры главного окна: `unified-{radar,replay,trading,monitor-offline,setup}-{360,390,1000,1440}.png`. Проверяются выбор раздела с клавиатуры, возврат из подключения сервера (Esc), отсутствие удалённого подключения для свежего профиля и сброс подтверждения заявки при уходе со страницы.
- На узком окне список разделов заменяется выпадающим меню, студия и форма заявки адаптируются по ширине. Неподключённый старый монитор показывает приглашение подключить сервер, а не пустую таблицу. Широкие таблицы старого монитора имеют собственную горизонтальную прокрутку.
- Для Mac использована опция локальной упаковки `--with-studio-source` с путём к собственному серверному checkout. Отдельный smoke-тест запустил **упакованный** исполняемый файл данных на свободном временном loopback-порту с очищенным окружением. Проверены идентичность сервиса, режим `local-read-only` и 12 архивных записей. Остановлена только копия smoke-теста; существующий слушатель 47831 не перезапускался.
- Менеджер проверяет фиксированный адрес, не наследует переменные среды для своего дочернего процесса и при штатном выходе останавливает только собственный процесс. Отказ запуска при занятом порте, отказ от рестарта чужого сервиса, некорректный ответ и остановка своего процесса покрыты отдельными тестами.
- Аутентификация и исполнение на реальных Walt, Финаме и частном сервере мониторинга не проверялись; для оценки интерфейса такие операции не требуются. Подпись для публичного распространения и автозапуск после перезагрузки не проверялись. Веб-страницы не менялись.

Кадры подключённого **тестового** монитора на 390: `unified-monitor-connected-390.png` и `unified-monitor-scrolled-390.png` (после горизонтальной прокрутки). Отдельно проверено, что неподтверждённая смена адреса сервера не отправляет предыдущий ключ по новому адресу. Для readback установленного приложения используется главное окно macOS с названием «RocketMon», лентой и пунктами меню, а не открытая параллельно веб-страница.
