# RcktMon

Мониторинг резких движений цены и объёма на бирже, с уведомлениями в Telegram.

Уведомления приходят, когда цена или объём торгов инструмента меняются больше чем на
заданный процент — за день или за последние N минут. Каналы:

- ММВБ — https://t.me/stoxxxxx_ru
- иностранные бумаги — https://t.me/stoxxxxx

## Что здесь

Это **клиент**. Кроссплатформенное десктопное приложение на .NET 10 и Avalonia — Windows,
macOS, Linux.

Серверная часть закрыта и живёт отдельно. Разделение вынуждено лимитами T-Invest API:
32 стрима на токен, 300 подписок на стрим, 15 запросов каталога в минуту. Один сервер
укладывается в этот бюджет и раздаёт результат многим клиентам; сотня клиентов со своими
токенами — нет.

Для мониторинга брокерские ключи не нужны. Доступ к торговле включается отдельно и только в нативном окне ручных заявок. Рыночный сигнал не может выставить заявку.

```
proto/rcktmon/v1/     контракт: gRPC, единственный источник правды
src/RcktMon.Protocol/ кодоген + конвертеры Decimal
src/RcktMon.Client.Core/ транспорт, reconnect/resume, хранилище котировок
src/RcktMon.App/      Avalonia: экраны, темы, локализация
src/RcktMon.Desktop/  точка входа
tools/RcktMon.FakeServer/ сервер-заглушка, чтобы разрабатывать UI без доступа к боевому
legacy/               WPF-версия 2023 года, только для чтения
```

## Запуск

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

Против боевого сервера — адрес и ключ доступа выдаёт оператор:

```bash
dotnet run --project src/RcktMon.Desktop -- --server https://ваш-сервер --key rm_ВАШ_КЛЮЧ
```

Дальше достаточно `dotnet run --project src/RcktMon.Desktop`: адрес запоминается, а ключ
уходит в системное хранилище секретов — Keychain на macOS, DPAPI на Windows, libsecret на
Linux, — а не в файл рядом с настройками.

Без сервера, чтобы просто посмотреть интерфейс:

```bash
dotnet run --project tools/RcktMon.FakeServer -- --instruments 500 --calm
dotnet run --project src/RcktMon.Desktop -- --server http://localhost:5299 --key dev
```

Заглушка по умолчанию генерирует 2000 инструментов — это нагрузочная цифра, а не ММВБ;
`--instruments 500` ближе к реальности, `--calm` убавляет искусственную волатильность.
Открытый `http://` клиент принимает только на localhost — на любом другом адресе он
потребует https.

Ещё у заглушки есть `--chaos`: она рвёт поток, присылает протухшие последовательности и
зависает. Он существует, чтобы поведение при обрыве связи разрабатывалось против настоящих
отказов, а не воображаемых.

## Десктопная студия: радар, бэктест и ручные заявки

Открыть из основного окна или приветствия: **Студия сигналов**. Запустить сразу без ключа старого сервера:
```sh
dotnet run --project src/RcktMon.Desktop -- --studio
```
На Mac `tools/macos/install-studio.sh` собирает локальный автономный **RocketMon Studio.app** в пользовательской папке Applications. Двойной клик открывает студию, не меняя настройки мониторинга. Это локальная сборка, не подписанный дистрибутив для распространения.

- **Сигналы и бэктест** читают только локальный Signal Studio (`127.0.0.1:47831`); сервис данных запускается отдельно. Сопоставляются контракт OKX и исторические котировки акции Alpaca SIP. Номинал 100 USDT виртуальный. При разрыве данных экран не подставляет искусственные цены. Для просмотра не нужно подключать брокера.
- **Ручная торговля → Walt.** Войти в Wallet через системный браузер (OAuth/PKCE). Открытие рыночного long/short: выбрать контракт, направление, маржу **в USDC** и плечо, проверить предпросмотр. Чтобы выйти, выбрать **Закрыть всю позицию**, а не противоположную сторону. Нужен торговый счёт для конкретного OAuth-клиента: успешный вход и список контрактов не подтверждают готовность счёта. Клиент не создаёт и не пополняет его при подключении. На диске сохраняются только публичные данные регистрации OAuth-клиента, не секреты.
- **Ручная торговля → Финам.** Ввести токен [Finam Trade API](https://api.finam.ru/) в приложении и выбрать нужный счёт. Токен и сессия не сохраняются. Демо и реальная торговля используют один адрес API: приложение не угадывает тип счёта. Доступны рублёвые акции MISX/TQBR, покупка и продажа лимитными заявками до конца дня. Проверяются брокерские параметры, лоты/штуки, шаг цены, собственные средства или позиция; тарифную комиссию определяет брокер. У API нет флага запрета маржи в этой заявке. Если торговые права не подтверждены явно, доступен только предпросмотр и чтение. Отмена активной заявки — у брокера.
- **Отправка** требует отдельного подтверждения неизменённых условий. При неопределённом результате (включая аварийное закрытие) блокируется новая отправка на этой площадке. На Финаме есть сверка по исходному счёту и клиентскому ID; на Walt проверьте заявки и позиции в Wallet. Разблокировка не повторяет заявку. Принятая заявка ещё не означает исполнение.

## Установщики

Публичного установщика новой версии пока нет. Для локального Mac доступен скрипт сборки выше; на других системах — `dotnet run`.
[Релизы WPF-версии](https://github.com/t3chn0pr13st/RcktMon/releases) остаются доступны;
она работает только на Windows и через отключённый legacy-API Тинькофф, то есть рыночных
данных больше не получает.
