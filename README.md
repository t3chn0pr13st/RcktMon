# RcktMon

Мониторинг резких движений цены и объёма на бирже, с уведомлениями в Telegram.

Уведомления приходят, когда цена или объём торгов инструмента меняются больше чем на
заданный процент — за день или за последние N минут. Каналы:

- ММВБ — https://t.me/stoxxxxx_ru
- иностранные бумаги — https://t.me/stoxxxxx

## Что здесь

Это **клиент**. Кроссплатформенное десктопное приложение на .NET 10 и Avalonia — Windows,
macOS, Linux.

Серверная часть закрыта и живёт отдельно. Разделение вынуждено лимитами T-Invest API:
32 стрима на токен, 300 подписок на стрим, 15 запросов каталога в минуту. Один сервер
укладывается в этот бюджет и раздаёт результат многим клиентам; сотня клиентов со своими
токенами — нет.

Прямое следствие для вас: **клиент никогда не спрашивает брокерский токен.** Рыночные
данные приходят с сервера уже посчитанными. Токен понадобится позже и только для
выставления заявок, когда эта часть появится.

```
proto/rcktmon/v1/     контракт: gRPC, единственный источник правды
src/RcktMon.Protocol/ кодоген + конвертеры Decimal
src/RcktMon.Client.Core/ транспорт, reconnect/resume, хранилище котировок
src/RcktMon.App/      Avalonia: экраны, темы, локализация
src/RcktMon.Desktop/  точка входа
tools/RcktMon.FakeServer/ сервер-заглушка, чтобы разрабатывать UI без доступа к боевому
legacy/               WPF-версия 2023 года, только для чтения
```

## Запуск

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

Против боевого сервера — адрес и ключ доступа выдаёт оператор:

```bash
dotnet run --project src/RcktMon.Desktop -- --server https://ваш-сервер --key rm_ВАШ_КЛЮЧ
```

Дальше достаточно `dotnet run --project src/RcktMon.Desktop`: адрес запоминается, а ключ
уходит в системное хранилище секретов — Keychain на macOS, DPAPI на Windows, libsecret на
Linux, — а не в файл рядом с настройками.

Без сервера, чтобы просто посмотреть интерфейс:

```bash
dotnet run --project tools/RcktMon.FakeServer -- --instruments 500 --calm
dotnet run --project src/RcktMon.Desktop -- --server http://localhost:5299 --key dev
```

Заглушка по умолчанию генерирует 2000 инструментов — это нагрузочная цифра, а не ММВБ;
`--instruments 500` ближе к реальности, `--calm` убавляет искусственную волатильность.
Открытый `http://` клиент принимает только на localhost — на любом другом адресе он
потребует https.

Ещё у заглушки есть `--chaos`: она рвёт поток, присылает протухшие последовательности и
зависает. Он существует, чтобы поведение при обрыве связи разрабатывалось против настоящих
отказов, а не воображаемых.

## Установщики

Готовых сборок для новой версии пока нет — идёт закрытая бета, запуск через `dotnet run`.
[Релизы WPF-версии](https://github.com/t3chn0pr13st/RcktMon/releases) остаются доступны;
она работает только на Windows и через отключённый legacy-API Тинькофф, то есть рыночных
данных больше не получает.
