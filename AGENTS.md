# RocketMon: куда вносить изменения

Этот репозиторий — нативный клиент Avalonia. По умолчанию новые задачи про радар, исследование стратегии, бэктест и «Студию» относятся к браузерной Signal Studio в RcktMon.Server. Сначала прочитайте docs/studio-project.md в серверном репозитории. Не подменяйте веб-релиз изменением десктопной вкладки. Desktop меняется, когда задача явно требует нативного клиента или общего контракта.
